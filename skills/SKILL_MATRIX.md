# Skill Matrix — AI Design Engineer

## Purpose
This matrix helps you choose the right production skill for each situation.

## How to use
- Start at the top for new projects.
- Use the middle for generation and governance.
- Use the bottom for production quality and orchestration.

---

## Skill decision guide

| Scenario | Recommended skill(s) | Why | Time estimate |
|---|---|---|---|
| New project kickoff | `core-system-prompt`, `ux-decision-framework` | Establish role, constraints, user tasks, and UX rationale | 10–20 min |
| Clarify product goals | `core-system-prompt` | Align the AI to product strategy and success metrics | 5–10 min |
| Make UX decisions | `ux-decision-framework` | Structure user journeys, task flows, and trade-offs | 15–30 min |
| Generate UI screens | `ui-generation-structured` | Create UI with explicit constraints and system rules | 20–30 min |
| Enforce design consistency | `design-system-governance` | Audit tokens, components, and patterns | 15–20 min |
| Convert UI to code | `code-generation` | Produce production-ready frontend code | 20–40 min |
| Review quality | `review-critique` | Score output and prioritize fixes | 10–15 min |
| Iterate output | `refinement-workflow` | Improve design/code until production ready | 15–30 min |
| Catch recurring mistakes | `anti-patterns-detector` | Identify issues before shipping | 10–15 min |
| Coordinate agents | `multi-agent-workflow` | Run a full pipeline with clear handoffs | 30–60 min |

## Quick reference

- Need a prompt baseline? → `core-system-prompt`
- Need UX reasoning? → `ux-decision-framework`
- Need a reproducible UI prompt? → `ui-generation-structured`
- Need consistency checks? → `design-system-governance`
- Need code output? → `code-generation`
- Need quality gate? → `review-critique`
- Need iterations? → `refinement-workflow`
- Need final audit? → `anti-patterns-detector`
- Need team orchestration? → `multi-agent-workflow`

## Notes
- The matrix is designed to help you choose the right skill, not to force a strict order.
- Use the beginner path to get started quickly.
- Use the expert path when quality and repeatability matter.
- Every project should include at least one review and one refinement cycle.
