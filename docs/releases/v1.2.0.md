# Skill Studio 1.2.0

Thai-first local app for the AI Design Engineer skill library. Choose a workflow
stage, prepare a prompt for Codex, or connect a custom text model in the app.

## Included

- Seven workflow stages, searchable canonical library (11 core + 2 community skills).
- Project Design Advisor 1.0.0: Idea, readiness G1–G8, Dev handoff and CR
  starters with scoped references, approval evidence and baseline preservation.
  Advisor prose and license are CC BY 4.0; other existing licenses are retained.
- Portable prompts with explicitly selected references and project context.
- Custom Base URL/model/Bearer key, Chat Completions and Responses protocols,
  model discovery, timeouts and cancellation. Ollama/LM Studio/OpenAI presets.
- Markdown answers, external-answer paste, recent history, JSON workspace
  import/export and Markdown download. Inputs survive provider failures.
- Loopback server, same-origin/token checks, bounded requests/responses,
  credential redaction and redirect rejection. Keys stay in server memory.
- Updated existing skill content 2.2.0 and generated native Codex discovery/UI metadata.
  Product version 1.2.0 and skill schema 2.1.0 are independent.

## Release assets

| File | Usage |
|---|---|
| `aide-skill-studio-1.2.0-windows-x64.zip` | Windows x64; Node 24.22.0 included. Extract fully, open `Start Studio.cmd`. |
| `aide-skill-studio-1.2.0-node.zip` | Existing Node >=22.12.0; Windows launcher or `sh start-studio.sh`. |
| `SHA256SUMS.txt` | Verify ZIP integrity before extraction. |

Archives include license notices, canonical skill content and a per-file hash
manifest. They exclude source workspaces, keys, node_modules and test fixtures.
Windows runtime is downloaded from nodejs.org and checked against the official
archive SHA-256 before packaging; its license is included. This is a portable
local browser app, with no system installer or automatic updater.

Read the [Thai guide](../studio-guide.md) and [measured validation](../studio-validation.md).
Custom provider compatibility and answer quality still require validation with
the user's chosen server/model. macOS/Linux startup has not been exercised here.

## Reproduce and prepare a GitHub draft

```bash
npm ci
npm ci --prefix apps/studio
npm run studio:test
npm run studio:package
node scripts/prepare-studio-runtime.mjs
node scripts/package-studio.mjs --runtime-dir=.release-runtime/node-v24.22.0-win-x64
node scripts/verify-studio-package.mjs --bundled-runtime
```

`--bundled-runtime` verification requires Windows. The Node-required archive can
be checked with `node scripts/verify-studio-package.mjs` on the current platform.
Outputs go to `dist/releases/`, which is intentionally ignored by Git.

The workflow **Prepare Skill Studio draft release** is manual (`workflow_dispatch`).
After committing and pushing the reviewed source to GitHub, open Actions, select
the workflow and enter `1.2.0`. It runs checks, builds/verifies both archives and
creates a **draft** Release on the selected commit. It refuses to replace an
existing Release. Review the draft and download/start its assets before publishing.
This local implementation session does not push commits, create a remote draft,
or publish a GitHub Release.
